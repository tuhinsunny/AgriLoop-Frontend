## 🌟 Features

AgriLoop offers a suite of features aimed at promoting sustainable waste management and empowering communities:

- ♻️ **Smart Waste Collection**: Utilize cutting-edge technology to detect, categorize, and collect waste efficiently.
- 🔄 **Resource Transformation**: Convert organic waste into valuable products like compost, fertilizers, and biogas.
- 👨‍🌾 **Empowering Farmers**: Connect farmers directly with consumers, eliminating middlemen and boosting rural economies.
- 🏘️ **Community Engagement**: Collaborate with municipalities and NGOs to ensure widespread participation and impact.

## 🚀 Getting Started

Follow these steps to set up the project locally:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/tuhinsunny/AgriLoop-Frontend.git
   ```

2. **Navigate to the project directory**:

   ```bash
   cd AgriLoop-Frontend
   ```

3. **Open `index.html` in your preferred web browser**.

   > Note: As this is a static frontend project, no additional build steps are required.

## 📂 Project Structure

Here's an overview of the project's directory structure:

```
AgriLoop-Frontend/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── apples.png
│   ├── banana.png
│   ├── ...
├── NGO_index.html
├── NGO_style.css
├── Service.html
├── Service.css
├── Service.js
├── contactus.html
├── checkout.html
├── ...
```

- `index.html`: Main landing page.
- `style.css`: Global styles.
- `script.js`: JavaScript for interactivity.
- `images/`: Contains all image assets.
- `NGO_index.html`: Page dedicated to NGO-related information.
- `Service.html`: Details about the services offered.
- `contactus.html`: Contact information and form.
